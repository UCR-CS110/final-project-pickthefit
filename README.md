# 👗 Pick The Fit

A full-stack fashion closet web application where users can manage their personalized digital closet. 

---

# 🚀 Features

## 🔐 Authentication
- User signup with secure password hashing (bcrypt)
- User login with credential validation
- Basic session handling using localStorage

## 👤 User System
- Unique usernames (stored in MongoDB)
- Personalized home page per user
- Dynamic rendering of logged-in user data

## 🏠 Home Dashboard
- Displays user profile info
- Followers/following UI (frontend mock data)
- Navigation to Closet page

## 👗 Closet (In Progress)
- Planned feature to store user-uploaded clothing items
- Each item will be linked to a specific user account

---

# 🧰 Tech Stack

## Frontend
- React.js
